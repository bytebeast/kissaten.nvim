# kissaten for iTerm2

[kissaten.nvim](../../README.md) theme for [iTerm2](https://iterm2.com), generated from the same palettes as the Neovim colorscheme.

Every file comes in all five styles (`kissaten_morning`, `kissaten_afternoon`, `kissaten_evening`, `kissaten_midnight`, `kissaten_graveyard`). The examples use `evening`; swap in the style you want. Replace `curl … -o` with a plain copy if you've cloned the repo.

## Install

```sh
curl -fsSL -o ~/Downloads/kissaten_evening.itermcolors \
  https://raw.githubusercontent.com/bytebeast/kissaten.nvim/main/extras/iterm2/kissaten_evening.itermcolors
```

In iTerm2, open **Settings → Profiles → Colors**, click **Color Presets… → Import…**, choose the file, then pick **kissaten_evening** from the same menu.
