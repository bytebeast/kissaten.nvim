-- brew a cup, the kissaten way
local M = {}

---@param beans string
---@param grams? number
function M.brew(beans, grams)
  local cup = { beans = beans, grams = grams or 18, hot = true }
  if not cup.beans:match("^%a+$") then
    error(("unknown beans: %s"):format(beans))
  end
  vim.notify("brewing " .. beans, vim.log.levels.INFO)
  return setmetatable(cup, { __index = M })
end

return M

-- why kissaten

Pretty, and you can actually read it

  • Comments you can read. 4.3:1 or better. Tokyonight's sit at 2.4 to 3.1.
  • A light style that passes. Every syntax color in morning is 6:1 or better, even on the cursorline, selection and diffs.
  • Diffs you can read. Changed text is underlined too, so a one-character edit doesn't vanish.
  • Color means something. Structure is cool, data is warm, and parameters get their own hue.
  • Built for color blindness. Red-green and blue-yellow modes remap diffs, git signs and diagnostics.
  • Roles, not 1,600 hex codes. Change colors.syn.parameter once and every language follows.
  • Fast, nothing to go stale. All groups rebuild in about 1 ms, so your changes always show up.

  • 60+ plugin integrationsAuto-detected from lazy.nvim or vim.pack
  • 20 tool themesTerminals, CLI tools, VS Code, Zed, Helix
  • Colorblind modes"red-green" or "blue-yellow"
  • High contrastBrighter comments, line numbers and hints
  • Subtle commentsFade comments behind code, keep docstrings
  • Saturation and accentMute the colors, keep the contrast, pick any accent
  • Transparent and borderlessFor terminal blur and shade-framed pickers
  • Rainbow variablesA color per local variable, JetBrains-style
  • Three hookson_palette, on_colors, on_highlights
  • Lualine themesOne per style, plus one that follows yours

-- try it

Pull up a chair

Neovim 0.9+ and a true-color terminal. Every option is in the README.

-- ~/.config/nvim/lua/plugins/colorscheme.lua
return {
  { "bytebeast/kissaten.nvim", lazy = false, priority = 1000, opts = {} },
  { "LazyVim/LazyVim", opts = { colorscheme = "kissaten" } },
}
{
  "bytebeast/kissaten.nvim",
  lazy = false,
  priority = 1000,
  config = function()
    require("kissaten").setup({ style = "evening" })
    vim.cmd.colorscheme("kissaten")
  end,
}
-- Neovim 0.12+
vim.pack.add({ "https://github.com/bytebeast/kissaten.nvim" })
